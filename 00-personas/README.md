# Personas

Colección de personas de Meridian Community. Cada perfil tiene su propia carpeta y puede incluir imágenes autorizadas, presentación y aportaciones.

## Perfil inicial

<p align="center"><img src="./imagenes/retrato-github.webp" width="315" alt="Retrato fotográfico original aportado para el perfil" /></p>

Imagen fotográfica aportada para la presentación. No se han añadido nombres, biografías ni datos de contacto sin verificación.

### ¿Cómo añadir más personas?

Crea una carpeta por perfil, sube un retrato con permiso para publicarlo y usa nuestra [plantilla](./PLANTILLA.md). Enlaza el nuevo perfil desde este índice.
