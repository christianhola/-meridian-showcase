## Add a resource
Open an issue with:
1. An accessible public GitHub repository and explicit license.
2. A short explanation of what works today.
3. Setup steps, test instructions and supported versions.
4. Requested permissions, external dependencies and support contact.

A maintainer reviews functionality and security before including the link. Source entries are stored in the community portal's `community/registry.json` for reproducible builds.

## What we never promise
No fake download counts, badges, benchmark claims, test results or installation commands. Public API contracts are marked as proposals until implemented and verified.
