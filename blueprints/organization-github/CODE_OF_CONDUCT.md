# Meridian Community Code of Conduct

We want developers worldwide to feel welcome and able to contribute constructively.

Be respectful, inclusive, curious and evidence-driven. Do not harass, discriminate, threaten, doxx, spam or share private user information. Disagreements about technical decisions are welcome; personal attacks are not.

Moderators may edit or remove posts, restrict access, and review appeals under published procedures. Report incidents privately to designated maintainers or moderators through an approved confidential channel. Never post personal reports as public issues.

**Before launch:** the organization owner must add a verified private contact method and an incident response owner.
