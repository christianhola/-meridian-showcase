# Contributing to Meridian Community

Welcome! We accept bug reports, docs, accessibility improvements, translations, starters, reviewed plugins and SDK proposals.

## Start in three steps

1. Fork the **specific public repository** you want to help and clone your fork.
2. Install dependencies following that repository's README (for the community Vite portal, use `npm install`).
3. Make a focused change, run that repository's checks and submit a pull request describing evidence and test results.

Do not assume every repository uses npm, TypeScript or Docker. Follow the language, package manager, toolchain and test commands documented for that project.

- Use `feat:`, `fix:`, `docs:`, `test:` or `chore:` prefixes where applicable.
- Link the related issue and explain any compatibility or security risks.
- Never include private logs, API keys, secret tokens or personally identifiable data.
- Read [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) and [SECURITY.md](./SECURITY.md).
- Propose a new catalog entry only with a public repository, declared license, maintained documentation and a reproducible test.
- Large changes need maintainer alignment before implementation.
