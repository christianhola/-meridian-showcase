# Security Policy — Meridian Community

Do not submit vulnerabilities, exploitable details, authentication tokens or customer records in a public issue.

## Scope
Community repositories expose only their intentionally published contents. The private Meridian platform and Meridian API are not in scope for unapproved testing.

## Reports
Once live, use the repository's **Report a vulnerability** option via GitHub Security Advisories when available. If that is not enabled, use a verified confidential owner-approved channel. Please include affected component, version, non-destructive reproduction steps and expected impact.

## Boundaries
Do not attack production, collect third-party data, or exfiltrate credentials. Changes affecting auth, permissions, data processing and dependency supply chains require security review.

Public disclosures are coordinated after remediation and approval from the responsible maintainer.
