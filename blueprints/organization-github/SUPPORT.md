# Getting Help

- General questions: open a GitHub Discussion in the corresponding public repository once Discussions is enabled.
- Confirmed bugs: use the repository's bug-report Issue template.
- Propose features or integrations: open a feature Issue describing use cases, scope and tests.
- Vulnerabilities: follow SECURITY.md and **report privately**, not through Issues.
- Discord: the official server has not been verified or launched yet; no invite is provided here.

Community support is volunteer-led and does not imply an enterprise response-time guarantee.
