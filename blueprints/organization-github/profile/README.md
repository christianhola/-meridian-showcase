## Build with us

| Area | Repository convention | Purpose |
| --- | --- | --- |
| Plugins & Widgets | `plugin-*` | Extensions and permission-scoped capabilities |
| MCP Servers | `mcp-*` | Model Context Protocol service connectors |
| Templates & Starters | `template-*`, `starter-*` | Verified getting-started projects |
| SDKs | `sdk-*` | Typed clients backed by real public APIs |
| Integrations | `integrations-*` | Connectors built with validated permissions |
| Community collections | `awesome-meridian` | Curated and reviewed project links |

## Our standards

- Public evidence, clear implementation status, and reproducible examples.
- Secure defaults; minimal permissions; no private user data or production credentials.
- Respectful collaboration across languages and skill levels.
- Contributions credited with consent.
- No misleading badges, installation commands or fictional partner claims.

## Your first contribution

Start by reviewing [CONTRIBUTING.md](../CONTRIBUTING.md). Open an issue before a major change, fork a suitable repository and submit a small PR with tests and documentation.
