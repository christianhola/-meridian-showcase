# Comunidad

El repositorio de GitHub es nuestro punto de encuentro. No hace falta crear una cuenta en Notion, contratar alojamiento ni utilizar una plataforma de documentación externa.

## Cómo participar

- **Preguntas e ideas:** [abrir una issue](https://github.com/christianhola/-meridian-showcase/issues).
- **Proponer cambios:** [enviar un pull request](https://github.com/christianhola/-meridian-showcase/pulls).
- **Colaboración responsable:** [guía de contribución](https://github.com/christianhola/-meridian-showcase/blob/main/CONTRIBUTING.md).
- **Normas comunes:** [código de conducta](https://github.com/christianhola/-meridian-showcase/blob/main/CODE_OF_CONDUCT.md).
- **Seguridad:** [política de seguridad](https://github.com/christianhola/-meridian-showcase/blob/main/SECURITY.md).

## Publicar una mejora documental

1. Abre el archivo Markdown correspondiente en `docs/`.
2. Selecciona **Edit this file** en GitHub.
3. Describe tu cambio, explica las fuentes y propón un pull request.
4. Revisa la compilación automática antes de integrar.
