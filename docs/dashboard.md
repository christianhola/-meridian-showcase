## Capturas reales del dashboard

Cuando haya imágenes aprobadas para publicación, guárdalas en `docs/public/screenshots/` y enlázalas aquí usando `/screenshots/nombre-del-archivo.png`. Elimina datos privados, correos, claves y tokens antes de subirlas.

> [!TIP] Guía para capturas
> Usa capturas legibles, recortadas y con un texto alternativo que describa lo que muestran.
